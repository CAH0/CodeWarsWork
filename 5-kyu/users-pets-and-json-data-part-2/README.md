<h2><a href=https://www.codewars.com/kata/6479b3a881616a003732a726/train/sql target="_blank">Users' pets and JSON data: Part 2</a></h2><h3>5 kyu</h3><p>You have been provided with a PostgreSQL table named <code>users</code>. This table includes a <code>jsonb</code> column, <code>info</code>, which holds JSON data. Here is a simplified schema of the table:</p><ul><li><code>id</code>: primary key, integer.</li><li><code>info</code>: JSON column which includes:<ul><li><code>name</code>: a string (user's name).</li><li><code>pets</code>: an array of JSON objects (each object represents a pet and has a <code>name</code> field and <code>type</code> field).</li></ul></li></ul><p>In this task, you need to extract and analyze the initial letters of the pet names to find the most popular ones. The query should return a list of the initial letters, the count of pets starting with each letter, and the names of the users who own pets whose names start with each letter. </p><p>However, there are additional conditions to consider:</p><ul><li>Each user should only be listed once per initial letter in the aggregation.
